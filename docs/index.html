LoZ Too

An online adventure game for Windows.

Download for Windows Join the Discord

What is this? LoZ Too is a free multiplayer game made by a small team. The launcher only downloads and updates the game files from this project's GitHub repository, which has the source and every release. It doesn't ask for payment details and doesn't install anything else.

  1. Put LoZLauncher.exe in its own folder (not Program Files).
  2. Run it. It downloads the game into a game folder beside it.
  3. Press Play. The launcher keeps the game up to date for you.

FAQ

Windows says the launcher isn't safe

The launcher isn't signed, so Windows warns about it. Choose More info, then Run anyway.

How do I update the game?

You don't need to do anything. The launcher checks for a new version every time it starts and installs it.

The game won't start or won't update

Make sure the launcher is in its own folder that you can write to (not Program Files), then run it again. If it still fails, ask in the Discord.

How do I report a bug?

In game, type /bug followed by what went wrong, for example /bug the shop window won't close after I sell. It goes straight to the team. You can also post in the Discord.

Where can I see the chat commands?

Type /help in game for the full list.
